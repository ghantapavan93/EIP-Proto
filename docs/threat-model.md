# Threat model (prototype scope)

| Threat | Where it enters | Mitigation in this prototype | Production note |
|---|---|---|---|
| Prompt injection via crawled pages | scanner → LLM proposer | Deterministic matchers are regexes and cannot be instructed. The proposer is extraction-only (no tools), receives page text wrapped as untrusted data, must return an exact span that code verifies as a substring, and can only *propose*. Test: `test_prompt_injection_in_scanned_content_changes_nothing`, `test_injected_instructions_in_the_artifact_cannot_create_edges`. | Same design; add per-source allow-lists. |
| Prompt injection via transcripts | harness → workflow model | Transcript wrapped as data; structured tool output; every compliance decision downstream is deterministic against ground truth; spans verified. | Same; add an injection canary transcript to the corpus. |
| PHI / PII exposure | transcripts, outputs, logs, model providers | The demo corpus is synthetic, but real text *can* enter: CSV ingest (`backstop ingest`, `POST /ingest`) and the "Try your data" sandbox. Both redact before storage or matching with `backstop.core.pii`: Medicare numbers (dashed, spaced, bare, any case), SSNs (dashed, spaced; bare 9 digits only next to "social"/"SSN"), dates of birth (numeric, ISO, month-name; 19xx years always, 20xx only next to a DOB word, so call dates and timestamps survive), US phone numbers (toll-free business lines such as 1-800-633-4227 are kept), emails (including spoken "dot com" form) and street addresses with a suffix or a PO box. The CSV `agent_name` is stored as initials, and replaced in the transcript text, unless `BACKSTOP_INGEST_KEEP_AGENT_NAMES=1`. Scored on `fixtures/pii_golden.yaml` (42 hand-written strings, 15 negatives: dollar figures, plan IDs like H1234-001, call timestamps, effective dates, toll-free numbers): precision 1.000, recall 0.935 (29/31). Misses are published: spoken names ("My name is ...") and addresses without a street suffix. The cases were written by the author of the patterns, so these are regression numbers, not a production estimate. **Egress guard:** an ingested transcript is sent only to a local Ollama model, or to Anthropic when `BACKSTOP_ALLOW_ANTHROPIC_REAL_DATA=1` is set; Groq, Gemini AI Studio and OpenRouter free tiers are refused per call before any network I/O (the result is ERROR with the reason; `RealDataGuard` in `harness/adapters.py`). The sandbox is local-only. `C-PII-01` still checks model output for the original three patterns only (MBI, dashed SSN, slash DOB). | Name detection needs NER (and published false positives). Move `C-PII-01` onto `core.pii`. A BAA with any hosted model vendor before setting the Anthropic flag. Transcripts from EIP's own export, never a vendor API by default. |
| Unauthorized actions | API | HTTP Basic with roles; mutating endpoints require engineer/admin; decisions require a named user; every audit row carries actor + role + correlation id, automation is `system:<component>`; denied attempts are audit-logged (throttled per username so a password-guessing loop cannot flood the log). | OIDC/SSO with role claims; per-rule ownership for edit rights. |
| Silent history edits | rule corpus, audit log | Loader refuses in-place edits of existing versions (closing an open window once is the only legal change, and it is audited). The audit table rejects UPDATE/DELETE (and TRUNCATE on Postgres) with database triggers; each row carries a SHA-256 chained to the previous row, so an inserted or reordered row fails `GET /api/audit/verify`. **Tamper-evident, not tamper-proof**: a database superuser can drop the trigger and rewrite the whole chain. Two external anchors catch that: evidence bundles embed the chain tip at export time, and an admin **audit checkpoint** (`POST /api/admin/audit-checkpoints`) issues a receipt kept outside the system; `GET /api/audit/verify?through_id=&tip=` fails once history before it is rewritten (`test_a_checkpoint_catches_a_full_consistent_rewrite`). | Branch protection on `rules/`; app role with INSERT/SELECT only on `audit_events`; write checkpoints to write-once storage (S3 Object Lock) on a schedule instead of by hand. |
| Duplicate side effects on retry | scans, runs, tasks | Unique keys on every operation (ADR-005). | Same. |
| Secrets | model key | Env var only; never logged; absent by default. | Secrets Manager; scoped keys. |
| Crawler harm to third parties | real pages | Six pages, once, identified UA, 2-second delay, robots-respecting intent, frozen snapshots, `BACKSTOP_CRAWLER_LIVE=false` by default. | Crawl only owned properties with the owner's consent. |
| Judge noise causing false blocks | judged contracts | Judged contracts cannot block; N runs with variance (ADR-006). | Judge canary set. |
| Wrong rule text | corpus | Citations on every version; disputed readings carried with both sources and a "verify with counsel" flag rather than silently resolved. | Compliance owns the corpus; counsel review on disputed nodes. |
| Public demo URL | Cloudflare Quick Tunnel | Only the nginx gateway (UI + `/api`) is published; it and the API's local port bind to 127.0.0.1, Postgres has no host port, Ollama stays on the host. The tunnel scripts refuse to run while any account has password == username. nginx adds CSP (`connect-src 'self'`), `X-Frame-Options: DENY`, `nosniff`, `no-referrer`, and a 20 r/s per-IP limit on `/api`. The SPA's 401s omit the Basic challenge, so no browser dialog pops. | Named tunnel behind Cloudflare Access (SSO) or the ALB in `infra/terraform`; no Basic auth. |
